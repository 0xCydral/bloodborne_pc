BLOODBORNE CRASH LOGS
=====================

This starts the game the same way as the Desktop shortcut and records everything, so the
person who gave you the kit can see why it crashes.

1. Close Bloodborne.
2. Unzip bloodborne-logs.zip (right-click > "Extract All...").
3. Double-click PLAY-WITH-LOG.bat.
   If Windows shows "Windows protected your PC": click "More info", then "Run anyway".
4. Play until the game crashes (for example: Continue, then wait for the load).
   Leave the blue window open while you play.
5. When the game closes, the blue window shows a file name and opens a folder with it selected:
   bloodborne-logs-<date>.zip on your Desktop. Send that file.

If the game does not open at all, that is fine too: wait for the blue window to finish and send
the file it makes.
